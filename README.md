# Crypto Max V26

A mobile-first Android app for organizing free crypto-reward opportunities. Arabic-first onboarding, RTL layout support, English/Arabic language switch, local reward tracking, search/filter, manual value estimates, and JSON backup export.

## Build APK in GitHub
1. Upload the **contents** of this folder to the root of your GitHub repository (including the hidden `.github` directory).
2. Open **Actions** → **Build Crypto Max V26 APK**.
3. Choose **Run workflow**, or push a commit to `main`/`master`.
4. Open the successful run and download **Artifacts → Crypto-Max-V26-APK**.
5. Extract the ZIP and install `app-debug.apk` on Android.

## Important
- This app is a tracker, not a wallet or exchange.
- It does not automatically claim rewards, connect wallets, trade, or guarantee income.
- Values and statuses are user-entered and not independently verified.
- Never enter a seed phrase/private key or pay a fee to unlock a supposedly free reward.
- The workflow builds a debug APK for personal testing. A signed release build requires a private signing key.
